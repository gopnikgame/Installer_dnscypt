# Инструкция Codex по работе с репозиторием

Эта инструкция действует во всём репозитории. Перед изменениями прочитать и использовать `.codex/skills/dnscrypt-installer-development/SKILL.md`.

- Начинать с `git status --short --branch`, проверки remotes и актуального `main`.
- Работать в отдельной коротко названной ветке; не использовать force-push и не переписывать общую историю.
- Не смешивать определение дистрибутива, пакетного менеджера и init-системы.
- Не считать наличие `systemctl` доказательством запущенного systemd; проверять `/run/systemd/system`.
- Сохранять работу без systemd: SysVinit, OpenRC, runit и OpenWrt/procd должны либо поддерживаться, либо завершаться до изменений с ясной ошибкой.
- Перед изменением DNS создавать резервную копию и проверять локальный DNS-запрос. Никогда не направлять `resolv.conf` на DNSCrypt, который не запущен на порту 53.
- Редактировать через `apply_patch`, сохранять чужие изменения и делать небольшие осмысленные коммиты.
- Перед коммитом запускать синтаксическую проверку всех shell-файлов, тесты, `git diff --check` и просматривать staged diff на секреты.
- Коммиты подписывать GPG. В отчёте указывать ветку, хеш, проверки и куда отправлена ветка.
